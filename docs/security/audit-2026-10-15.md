## 1. Охрана при перезагрузке (Helper/ks)

Дефекты:
- B1/B2 (555-558, 788-789): `on` один раз, результат не проверяется, метка стирается. **Причина инцидента.**
- B3 (360-364, 771): при выключении метка перезаписывается; `physical_services` не видит `(*) Name` (выключенные) →
  второе выключение до восстановления теряет список.
- B4 (481-487, 555): включение только при `BLOCKING=1`; pf не загрузился / сторож упал → сеть выключена без срока.
- B5 (765-768): ветка «сторож выключен в Login Items» не восстанавливает существующую метку.
- B6 (771-773): службы по имени; переименование/удаление → `on` молча не работает.
- B7 (556): `networksetup` без таймаута в секундном цикле.
- B8: uninstall и `ks netrestore` стирают метку без проверки; обновление метку не смотрит.
- Баннер (App/KillSwitchControl.swift:1230, Banners.swift:61) только когда сторож НЕ работает — в инциденте не было.
- Любой SIGTERM сторожу (Activity Monitor, `kickstart -k`) выключает сеть, не только выключение Мака.

Починка (минимальная):
1. Метка `имя<TAB>устройство`, старый формат читается.
2. Выключение сливает с существующей меткой, пишет атомарно (tmp + mv).
3. Одна функция `net_back` для watch_pass, netrestore, install.sh, uninstall.sh: на каждую службу проверить
   `-getnetworkserviceenabled` = Enabled и устройство в `ifconfig -l`; по устройству, если имя пропало;
   метку стирать только когда всё подтверждено.
4. Повтор каждый проход, в фоне с таймаутом, лог не чаще раза в 30 с.
5. Жёсткий запасной путь: через 90 с после старта сторожа (или метка старше 10 мин) — включить в любом случае,
   строка в журнал; если не вышло — `NETWORK STILL OFF` раз в минуту.
6. `net_back` и в ветке Login Items.
7. Баннер: метка есть и (сторож не работает ИЛИ метке > 20 с). netrestore не отказывает после 20 с.
8. install.sh — netrestore до обновления сторожа; uninstall.sh — net_back, затем последний шанс: включить все
   выключенные en*/bridge*, только потом удалить папку.
9. Тесты: новый `Helper/tests/netguard.sh` со stateful-заглушкой networksetup: `on` молча не срабатывает 2 раза
   (инцидент), не срабатывает никогда + SECONDS=95, интерфейс запаздывает, двойное выключение с `(*)`,
   переименование/удаление, старый формат метки, Login Items, возраст netrestore, uninstall без метки; юнит-тест баннера.
10. Проверка выпуска: две перезагрузки подряд на живом Маке, Wi‑Fi работает.

## 5. Рефакторинг

Ключевое:
- **mihomo сейчас ядро по умолчанию.** Xray работает только для подписок с `/json` (Remnawave) и своих
  vless/vmess/trojan/ss. Убрать mihomo можно только после #68 (Xray из обычных списков серверов). Клэш-правила
  подписок пропадут: весь трафик через сервер, включая то, что провайдер пускал напрямую.
- Hysteria2, tuic, WireGuard, ss-плагины умрут вместе с mihomo, если не расширить генератор Xray.
- Настройки fail-closed: `tailscale=` и `core=mihomo` один выпуск принимать и игнорировать, иначе обновление = блок.
- Группу `_ksnetbird` нельзя удалить, пока в netbird.plist стоит `GroupName _ksnetbird` — NetBird не запустится.
  Одно последнее касание: вернуть его plist как было и перезапустить, потом удалить группу.

Объём к удалению: mihomo ~3.4–3.9 тыс. строк, NetBird/Tailscale ~1.05 тыс., остатки маршрутизации ~0.5 тыс.;
